Booking on your phone

The same one-tap filling, in Firefox for Android. Chrome on phones cannot run extensions.

← TTD Govinda Autofill (Free)

Why not Chrome? Chrome on Android and on iPhone does not allow extensions at all, and TTD's own app is closed. Firefox for Android is the one widely used phone browser that runs extensions, and it is free.

Android: five steps, once

  1. Install Firefox from Google Play.
  2. In Firefox, tap the menu ⋮ → Extensions, search for TTD Govinda Autofill and tap Add.
  3. Open it once from ⋮ → Extensions → TTD Govinda Autofill: read the short notice, tap I agree, and add your pilgrims (name, age, gender, Aadhaar or passport). Families and a password are optional.
  4. On booking day, open ttdevasthanams.ap.gov.in in Firefox and log in as usual. Pick the date, slot and number of persons.
  5. On the Pilgrim Details page, tap the orange 🙏 Fill pilgrims button at the bottom right (or open the extension from the menu and tap Fill this page). Check every row, then press Continue yourself.

Your details stay on the phone, encrypted if you set a password. The extension never presses Continue or Pay and never touches a CAPTCHA.

Also possible, not tested by us

  • Vivaldi for Android can install the Chrome version straight from the Chrome Web Store (Extensions → Open Chrome Web Store → Add to Vivaldi).
  • iPhone: the Orion browser can install Chrome extensions (Settings → Extensions), but its maker calls that feature a beta.

Without any extension

  • Gboard clipboard: copy each pilgrim's name, age and ID number once and pin them in Gboard's clipboard. On the booking page, tap a box, tap the clipboard icon, tap the item. Gender and ID type still need a tap each.
  • Samsung Keyboard: Settings → Text shortcuts, for example p1n for the first pilgrim's name.
  • A laptop at home: Chrome Remote Desktop (free) lets you drive the laptop, with this extension, from the phone.
